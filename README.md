# ▶️ How to Run

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Open the project

```bash
cd <project-folder>
```

### 3. Run a JavaScript file

Using Node.js:

```bash
node filename.js
```

Example:

```bash
node ArraySimple/findMax.js
```
